Icon set: Tabler Icons (outline) - the same set Noctalia uses. MIT licence.
install.sh downloads the real Tabler icons into this folder automatically (needs internet).
Offline, the bundled Lucide-style fallbacks are used instead.
Files starting with kc- are simple hand-drawn outline icons (bell, camera, video) and are never replaced.

To use your own icon (e.g. from svgrepo.com): put the .svg here and change the file name
on the matching line of the  icons  list in contents/ui/Config.qml.

The icons keep their own licences (Tabler: MIT, Lucide: ISC); see NOTICE.md. Everything else in Kontrol Center is GPL-3.0-or-later.
